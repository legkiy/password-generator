# Password Generator CLI

Интерактивная терминальная утилита для создания случайных паролей. Проект написан на Go.

## Возможности

- создание криптографически случайных паролей;
- настройка длины пароля;
- исключение символов из набора для генерации;
- сохранение настроек между запусками;
- копирование пароля в буфер обмена;
- сохранение пароля в новый текстовый файл;
- отсутствие истории созданных паролей.

Настройки сохраняются в системной папке конфигурации пользователя, в каталоге `PassGenerator`. Пароли там не сохраняются.

## Скачать и запустить

Готовые архивы находятся на странице [Releases](../../releases). Выберите архив для своей системы и распакуйте его.

### macOS (Apple Silicon)

Скачайте архив с названием `macos-arm64` для компьютеров с процессором Apple M1, M2, M3 и новее. Откройте `start.command` двойным кликом.

Если macOS покажет предупреждение о непроверенном разработчике, нажмите правой кнопкой на `pass-generator`, выберите **Открыть**, затем подтвердите запуск. После этого запускайте `start.command`. Приложение пока не подписано сертификатом Apple.

### macOS (Intel)

Скачайте архив с названием `macos-amd64` и откройте `start.command` двойным кликом. При предупреждении подтвердите запуск файла `pass-generator` так же, как в инструкции выше.

### Windows

Скачайте архив с названием `windows-amd64` и запустите `start.bat` двойным кликом.

### Linux

Скачайте архив с названием `linux-amd64`, распакуйте его и в терминале выполните:

```bash
chmod +x pass-generator
./pass-generator
```

## Использование

После запуска выберите пункт меню:

1. Создать пароль.
2. Изменить длину пароля.
3. Указать символы, которые нельзя использовать.
0. Закрыть приложение.

После создания пароля его можно скопировать в буфер обмена или сохранить в новый файл. При сохранении приложение не перезаписывает уже существующий файл.

## Сборка из исходного кода

Требуется Go версии, указанной в [go.mod](go.mod).

```bash
go run .
```

Для создания исполняемого файла:

```bash
go build -o pass-generator .
```
